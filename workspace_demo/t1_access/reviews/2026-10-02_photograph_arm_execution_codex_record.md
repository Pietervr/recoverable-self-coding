## 3. Dose and zero construction to freeze

**First pilot: code-value grayscale, independent masks at each level.** This is a precise image-array manipulation, not calibrated display luminance or a transferred human threshold. Canonicalize orientation and source color profile to sRGB; composite any alpha on RGB(0.5,0.5,0.5). Fit the complete photograph inside 384×384 while preserving aspect ratio: scale its longest side to 384, round the other dimension to the nearest integer (ties to even, minimum 1), and center on a 0.5 canvas (an odd extra padding pixel goes on the right/bottom). Use bicubic resizing with antialiasing; commit the exact implementation/version/settings before go. Then form grayscale `g=0.2126 R+0.7152 G+0.0722 B` directly in normalized **sRGB code values**. These weights without linear-light decoding define luma, not physical luminance. No dose-dependent crop, object box or image-token length. [sRGB transfer/conversion reference](https://www.w3.org/TR/css-color-4/#color-conversion-code)

Choose global `μ=0.5` and signal/noise RMS `r=0.10` in that code-value space. On the final canvas, `S=r(g−mean(g))/RMS(g−mean(g))`; reject a constant/invalid photo during source qualification rather than invent a divisor. For each noise cell draw one 384×384 array of Gaussian values independently of photograph/label, subtract its canvas mean and rescale to RMS r. Mix the scalar grayscale arrays, then replicate the result into all three RGB channels. These are Gaussian draws **subsequently centered and normalized**; the resulting pixels are not independent unconditioned Gaussian samples. Freeze the PRNG and seeds/nonces; use FP64 for generation/mixing/reductions and commit that implementation in the execution manifest.

Use `I(a)=μ+aS+sqrt(1−a²)N`, clip each value to [0,1], and quantize as `round_ties_to_even(255 I)` to 8-bit three-channel RGB in lossless PNG. Freeze the PNG decoder and native processor/version/settings, including any later resize and pixel normalization; hash both serialized pixels and delivered tensors. Five nominal **component-power** interior strengths:

| Nominal dB | a, rounded for display | Predictor coordinate |
|---:|---:|---|
| −18 | 0.124906614 | 8a |
| −12 | 0.243620490 | 8a |
| −6 | 0.448062506 | 8a |
| 0 | 0.707106781 | 8a |
| +6 | 0.894002232 | 8a |

Endpoints: a=0/k=0 noise-only; a=1/k=8 clean. Generate exact interior values by `a=sqrt(10^(d/10)/(1+10^(d/10)))` in the frozen precision, save sufficient digits and hash the serialized grid. Do not use the rounded table as the implementation. The family link is logistic in **amplitude k=8a**, not dB or level index. These values are an engineering proposal spanning weak-to-strong inputs, **not measured threshold placement**. Require an interpretable interior recognition curve; a grid that fails is amended with fresh held-out validation, never rescued by PILOT-specific staircases. Contrast is outside this pilot.

**Masks are independent across concept/photo/carrier/level/replicate cells.** Keep a frozen opaque trial nonce mapping independent of target identity/pixels. Use two masks at each nonclean level, including catch; capture clean once/photo/carrier. C1 reuses its matched target's **first mask only** at −12, −6 and 0 dB, with the same canvas/carrier/dose/processing; each primary concept's own draws remain independent. Record photo/background differences: equal canvas/noise is not an assertion of identical object-scene backgrounds. Independently qualify isolated-object sense/scene correspondence and report residual matching limitations.

**Zero has its own code path:** construct `μ+N` without loading the photo or consulting its mean, spectrum, crop, object mask, target label or target-dependent geometry. Fixed canvas/grid/template; no filename, EXIF, label, path or caption enters model tokens. Do not orthogonalize N against S, since that makes catch noise target-dependent. Equal S/N RMS gives constant expected mixture power, not exact realized power: record their realized correlation/cross term and mixture RMS. New catch draws are genuine external variation; identical zero inputs would require deduplication and a revised schedule. Clean mask seeds disappear, so duplicating them supplies no new evidence.

### What “delivered SNR” means

Report nominal `10 log10(a²/(1−a²))` plus RMS/mean/correlation and clipping/quantization statistics. Let T be the exact input pipeline through clipping, serialization, resizing and native pixel normalization, with identical settings for all references. Define

`s_del = T(μ+aS) − T(μ)` and
`e_del = T(μ+aS+sqrt(1−a²)N) − T(μ+aS)`;

report `10 log10(||s_del||²/||e_del||²)` in the delivered tensor, with zero numerator/denominator endpoints recorded explicitly. These pixel references need no model forward. The noiseless reference uses the **same a**, not the clean a=1 image. After nonlinear/clipping/quantization effects this is a **reference-based effective corruption ratio**, not uniquely recovered additive signal/noise. Also retain pre-clipping component powers, post-quantization pixel statistics, fraction of clipped pixels and measured geometry. Inspect severe clipping or strength-ordering defects in development; normalization does not by itself assure a recognizable full-dose photograph.
